## 本轮完成的功能

### A. 选择语义对齐 SuperSplat 3（3.2.0）

上游事实（读 `playcanvas/supersplat` v3.1.2 源码核实，MIT）：

```js
const selectionMethod = () => useDepth ? 'pick' : footprint > 0 ? 'footprint' : 'centers';
```

| depth | footprint | 屏幕空间手势 | 本仓库实现 |
|---|---|---|---|
| off | 0 | 穿透中心判交 | GPU 判交（mode mask/rect，footprint=0）|
| off | >0 | 投影椭圆 vs 区域，**穿透** | GPU 判交 + `footprint` 标量（GLSL 移植）|
| on | 0 | 可见集合 ∩ 中心在区域 | pick ids ∩ GPU 中心判交（`retainVisibleIds`）|
| on | >0 | 区域内可见覆盖 | 像素拾取（`pickRectIds` / `pickMaskIds`）|

- `footprint` 是**数字 0/1**（非布尔）；体积工具（sphere/box/球刷）用 3D **支撑函数**判定；
- GLSL 移植细节：屏幕空间模式采样投影椭圆（mask：中心+三轴 ±0.5/±1.0 共 7 点；rect：解析判定 + 矩形角点二次型），体积模式用 `splatBasis`（`transformA.w`/`transformB` 还原四元数与尺度）+ 最近点支撑；
- **删除 3.1.3 的 surface-map 比较方案**（无跨帧时序风险，代码更简单）；
- 球刷重构为路径一次 dispatch：`camera.intersectMany`（每 splat 一次深度 pass + `picker.readDepths` 分块批量回读 + 相机姿态快照）+ shader mode 4（点球 + 相邻点胶囊 + AABB 裁剪 + footprint 加宽 + footprint=0 时笔画 mask 门控），路径点用 **RGBA32F 纹理**上传；一条笔画 = 1 次 dispatch / 1 个历史 op。

### C. 加载崩溃修复（3.3.2）

现场报错：`Cannot read properties of undefined (reading 'width') at I1.attach`（Electron 内建服务 5173）。

根因：`SplatOverlay.attach` 读 `instance.orderTexture.width`；引擎（PlayCanvas 2.21.3）里
`orderTexture` **只在 WebGL2 创建**（WebGPU 用 `orderBuffer`），且 `instance.sorter` 惰性建立 →
"选中早于实例就绪"或"WebGPU 后端"都会命中。修复：就绪判断 + `orderReady` 门控 + `onUpdate` 重试
（`onPreRender` 不可靠：scene 设了 `autoRender=false` 会跳帧）+ WebGPU 一次性告警；`splat.ts` 两处
`.sorter` 访问加 `?.`。

### D. 渲染诊断（3.3.3 / 3.3.4）

- `src/render-diagnostics.ts`：`renderDiagnostics(splat)` 汇总
  `gsplatComponent / hasInstance / hasSorter / hasOrderTexture / entityInScene / entityEnabled /
  instancingCount / pendingSortedCount / streamsTexture / orderBufferMB /
  maxStorageBufferBindingSizeMB / maxBufferSizeMB / maxTextureDimension2D`；
- 加载后 4s 自检，不可绘制则弹窗（含具体数字与建议），控制台命令 **`splatDiag()`** 打印同样信息；
- 判定包含 `instancingCount > 0`（= 0 即"一个实例都没画"，正是"打开不显示"的直接信号）。

## ⚠️ 明天的第一件事（未解决问题）

**用户实测：`LFS-文物-鎏金七宝阿育王塔(北宋)-修剪.ply` 打开后空白；同一构建里小模型正常。**

已排除与已确认：

- 3.3.2 的修复**没有**破坏渲染：新增像素级验证显示正常模型 29.6%~30.2% 非背景像素、`maxChannel 255`；
- 用户在 **WebGPU（实验）后端**；小模型能显示、只有这个超大模型不行；
- 最可能原因：WebGPU 把排序结果放在**存储缓冲**（每高斯 4 字节），受
  `maxStorageBufferBindingSize`（默认 128 MB ≈ 3350 万高斯）与 `maxBufferSize`（256 MB）限制，
  越限则分配失败 → 0 个可绘制实例 → 空白且不报错；另有 `maxTextureDimension2D`（8192）约束。

**待用户回传（两种结果对应两条路）**：

1. **切回 WebGL2 后能显示** → 结案；若要支持 WebGPU 下的超大模型，需在 `createGraphicsDevice` 时申请更高
   limits（`requiredLimits`），属独立任务；
2. **切回 WebGL2 仍空白** → 让用户提供弹窗文字或 `splatDiag()` 输出，据数字继续查数据路径
   （点数/纹理尺寸/流式 LOD/内存）。

## 打包流程（固定，已按此执行 6 次）

1. bump `package.json` 版本 → `npm run build`（版本号在构建时内联，**必须先 bump 再 build**）；
2. patch `node_modules/app-builder-lib/out/util/appFileCopier.js` 的
   `pmApproaches` → `[node_module_collector_1.PM.TRAVERSAL]`（先 `.bak` 备份；注意替换后会多一个分号，无副作用）；
3. `npx electron-builder --win portable --config.npmRebuild=false`（后台跑，约 1 分钟）；
4. 还原 patch：`Copy-Item "$f.bak" $f -Force` 并删除 `.bak`（**务必还原**，否则 node_modules 长期处于魔改状态）；
5. 校验：`npx asar extract release\win-unpacked\resources\app.asar <tmp>` → 检查 `package.json` 版本、
   新代码字符串是否在 `dist/*.js` 里、无 `dist/test-model.ply` 残留；
6. 全链验证（tsc / eslint / lint:locales / build）必须在 bump 之后的源码上跑通。

## 环境与工具教训（避免重复踩坑）

- **不要用 PowerShell 写 TS/JSON 文件**：`Set-Content -Encoding UTF8` 曾给 `package.json` 写入 BOM，导致
  `import version from '../package.json'` 解析失败（构建报 `Unexpected token ''`）。要用就用
  `[System.IO.File]::WriteAllText(path, text, New-Object System.Text.UTF8Encoding($false))`；批量改文本优
  先写临时 Node 脚本（本次加 locale key、换 key 顺序都是这么做的，用完即删）。
- **GitHub API 匿名限流 60/小时**：本会话把我和子代理的配额都跑满了（403）。需要上游文件（如
  `select-box.svg`）时等配额恢复再取；raw.githubusercontent / jsDelivr 在本环境**不可达**，只有
  `api.github.com` 与 npm registry 通（用 contents API + base64 解码，避免 `Invoke-RestMethod` 把 XML 响应解析坏）。
- **npm allow-scripts 拦截 electron postinstall**：V3-0 的 electron 43.4.0 二进制是从 V2-5 拷贝的；
  重装 node_modules 后需重新补 `node_modules\electron\dist`。
- **5173 端口不是 dev server**：`electron-main.js` 用 `findAvailablePort(5173)`，打包版 Electron 内建静态
  服务就在这个端口——现场报错里的 `127.0.0.1:5173/index.js` 即打包版。
- Node 24 可用 `--experimental-strip-types` 直接跑 `src/*.ts`（需显式 `.ts` 后缀、类型要 `export type`）；
  `.mts` 脚本同理。
- `dist/` 不纳入 git（`.gitignore`），但打包会把它打进 asar —— 临时测试文件必须清理。
