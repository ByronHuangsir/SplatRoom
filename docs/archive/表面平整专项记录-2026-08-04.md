## 1. 功能背景与架构

「表面平整」是 SplatRoom 的后期处理工具，目标是把 3DGS 模型表面上的**突起（鼓包）压平**，让重建模型的表面更干净。

| 模块 | 文件 | 职责 |
|---|---|---|
| 分析器 | `src/geometry/surface-analyzer.ts` | 每个高斯的协方差特征分解（形状分类）、离群点检测 |
| 算法引擎 | `src/geometry/surface-refiner.ts` | `refineSurface()`（L1 压缩）/ `refineSurfaceLevel2()`（L2 边缘+散点） |
| UI 面板 | `src/ui/surface-panel.ts` | 两级参数滑块 + 应用按钮 + 结果展示 |
| 事件串联 | `src/editor.ts` | `surfaceRefine.apply` / `surfaceRefine.level2` 事件 → 调用算法 → `replaceData` |

**数据模型**：高斯泼溅 = 位置(x,y,z) + 旋转四元数(rot_0..3, wxyz) + 对数尺度(scale_0..2) + 透明度(logit) + 颜色(f_dc) + state(0=可见)。

## 3. 初始状态分析（11:35 前后）

### 3.1 L1 参数逻辑梳理（只读分析产出）

面板是**两级独立操作**（各自按钮、各自撤销），输入同一份 GSplatData，输出新数据替换原模型。

**L1 `refineSurface`（3 个参数）**：对每个高斯做协方差特征分解（Jacobi），按「最大尺度 / 局部平均尺度」判突起离群点，只处理离群点。

| 参数 | 默认 | 逻辑 | 当时发现的问题 |
|---|---|---|---|
| strength（0-1） | 0.6 | 压缩目标 = 局部均值 × (1+0.5×strength)，压缩系数钳制 ≥0.2 | 压完仍突兀 |
| edgeSplit | 开 | ⚠️ **只计数不分裂**（`splatsSplit` 是假数字） | 名不副实 |
| smoothNormals | 开 | ⚠️ **开关未接线**（`alignNormalToQuat` 无条件执行） | 无效开关 |

内置固定参数：`cellSize=对角线×1.5%`、离群阈值 **2.5**、尺寸上限 5% 对角线（超巨物跳过）。

**L2 `refineSurfaceLevel2`（6 个参数）**：空间哈希邻居统计 + 异步分块（8000 点/chunk 防 UI 冻结）。

| 参数 | 默认 | 问题 |
|---|---|---|
| radiusFraction | 0.01 | 核心（自适应搜索半径 = 对角线 × 值） |
| edgeRadiusScale | 0.5 | 正常 |
| edgeNbrFrac | 0.25 | 正常 |
| removeScatter | 开 | 正常 |
| scatterMinNeighbors | 2 | ⚠️ **死参数**（声明了从未读取） |
| opacityThreshold | 0.3 | ⚠️ **死参数**（同样从未读取） |

散点判定实际是硬编码加权评分：`score = 0.55×(1−邻居/中位数) + 0.45×(1−sigmoid(opacity)) > 0.6 → 移除`。

### 3.2 L1「未生效」根因（用户追问）

链路排查：`SurfaceRefineOp.do() → splat.replaceData(newAsset)` 是通的，问题在**算法**。

判定公式 `score = maxScale / localAvgScale > 2.5` 的致命缺陷：

1. **局部均值含自身 + 同类鼓包**：鼓包高斯互相「抬举」局部基准。鼓包 0.25 vs 表面 0.05 各半时，`localAvg=0.15`，`score=1.67 < 2.5` → 检不出。**真实鼓包通常 1.5~3 倍，恰好漏检**。
2. **阈值 2.5 过高**。
3. **压缩目标 1.3×localAvg**：压完还是 2.78×localAvg，视觉变化小。
4. **localNormal = 自身法线**（注释还写着 "skip neighbor PCA"）→ `alignNormalToQuat` 是恒等操作，法线对齐空转。

快速验证法：控制台 `[SurfaceRefine] outlier stats:` 看 `outlierCount`（0 = 检测问题；>0 但无变化 = 压缩幅度问题）。

## 4. 改进历程（每轮：动机 → 方案 → 结果）

### 4.1 移除 L2 UI（仅 UI）—— 11:35

- **动机**：用户决定先聚焦 L1，去掉 L2 的干扰。
- **方案**：只删 `surface-panel.ts` 里的 L2 控件（divider/区块标题/6 控件/apply 按钮）+ `_level2Params` 字段。**算法 `refineSurfaceLevel2()`、editor.ts 事件、locale 死 key、scss 死样式全部保留**（无害死代码）。
- **结果**：面板只剩 L1 的 3 控件 + 结果标签。

### 4.2 L1 四项修复 —— 下午①

- **动机**：用户采纳「未生效根因」诊断里的建议方案。
- **方案**：
  1. **排除自身统计**：`localCount-=1; localSum-=maxScale` → 聚簇鼓包能检出。
  2. **阈值 1.5 可调**：`SurfaceRefineOptions.outlierThreshold`（默认 1.5），面板新增「离群阈值」滑块（1.0~3.0），editor.ts 类型透传，locale 双语。
  3. **压缩目标压向 localAvg**：`targetMax = localAvg`（原来 1.3×）。
  4. **邻域 PCA 真实法线**：27 邻域位置协方差 Jacobi 特征分解，最小特征向量 = 局部法线（邻居 <3 回退自身法线），符号对齐自身法线。
- **验证**：默认 `modified 481`（修复前 0）；激进 `modified 1677`；截图 861KB→904KB→1.04MB。

### 4.3 卡死排查 + 性能优化 —— 下午②

- **动机**：用户报告「卡死」。100k 高斯 Phase 2 = 2717ms，线性增长（50 万 ≈14s、100 万 ≈27s、200 万 ≈54s）→ 主线程同步阻塞 = 卡死。
- **两个卡死热点**：
  1. 邻居收集 `for(const idx of m)` 达上限 1024 后**仍遍历整个 cell**（上限只限制 push 不限制遍历）。
  2. PCA 对**所有**点做（O(N×1024)）。
- **方案**：邻居收集达上限即 label-break（严格 O(上限)）；`MAX_PCA_NEIGHBORS` 1024→64；**只有 `isOutlier` 才做 PCA**（95%+ 跳过）。
- **验证**：100k 点 Phase 2 2717→**75ms（36×）**，总 3.3s→0.7s；检出结果不变（481/1677/6770）。
- **⚠️ 插曲（最重要教训）**：重构时在源码里制造了**重复 else-if 语法错误**，而 rollup 的语法错误消息是 "SyntaxError"/"Unexpected token"——**不含 "error:"**！一直用 `grep "error:"` 检查构建 → 漏掉 → 构建静默失败 → dist 陈旧 → 运行时表现诡异（循环只跑 1 次、计数矛盾），花了 20+ 轮排查。**最终用 `npx tsc --noEmit` 定位修复。教训：构建验证必须 tsc 或看完整构建输出。**

### 4.4 真分裂 v1 —— 下午③

- **动机**：用户反馈「做完后表面出现半透和漏洞，似乎高斯被干掉而不是被分裂」。
- **根因**：Phase 3 只改 scale/rotation，**不分裂**。大鼓包压缩后投影面积缩 (target/max)²，opacity 不变 → alpha 累积不足 → 半透；少数大高斯构成的鼓包压后中空 → 漏洞。
- **方案**（`surface-refiner.ts`）：
  - 加 `quatToTangentBasis(q)`（旋转矩阵 c0/c1 列 = 切平面基）。
  - 压缩后算 `flatR = max(压缩后中轴, 压缩后短轴)`，`k = ceil((flatR/splitTarget)²)` clamp [1,64]，k≥2 时分裂：原高斯缩为 splitTarget 扁盘 + 追加 k-1 个副本沿切平面 n×n 网格（间距 2·flatR/n）。
  - 新 Phase 3.5：**扩容所有属性 storage**（替换为更大的 TypedArray + 更新 `vertex.count` / `numSplats`），颜色/opacity/SH/state 复制源，位置按切平面偏移。
- **验证**：4180→5579（append 1399），截图无破损。
- **遗留**：副本未沿法线下压到表面（薄雾层问题）。

### 4.5 分裂 v2（pancake 漏算）—— 下午④

- **动机**：用户实测仍有半透漏洞。
- **v1 数学缺陷**：`flatR = max(中轴,短轴)` 对细长 pancake（a1=10L, a2=L）**低估 k ≈ 8 倍**（实际要 k = tA·tB/L² 面积比，不是 max²）。
- **方案**：
  - 切平面两半轴 `tA=压缩后最大轴, tB=压缩后中轴`。
  - 矩形网格 `nA=ceil(2·tA/splitR), nB=ceil(2·tB/splitR)`（直径分段，副本 1σ 重叠密实）。
  - k = clamp(nA×nB, [1, MAX_SPLIT=512])，clamp 后按椭圆长宽比重排。
  - `discR = clamp(sqrt(tA·tB/k), [splitR×0.6, splitR×2])` **面积守恒自适应**。
  - 总预算 EXTRA_BUDGET=200k。
  - SplitRecord 字段改 `n, m, sp1, sp2`（矩形网格 + 双间距）。
- **验证**：6 个 (0.4,0.05,0.05) 巨型 pancake 模型 append 4632（v1 ≈600），激进 14255。

### 4.6 分裂 v3（覆盖原高斯范围）—— 下午⑤

- **动机**：用户实测「分裂不够，漏洞和半透依然存在」，并指出关键：**分裂范围不足以覆盖原先的高斯球**。
- **v2 缺陷**：tA/tB 用**压缩后**尺度——球状大高斯 R 被压到 0.52R 后，网格跨度只有原直径 52%（u 方向只覆盖一半），**外圈环形区域全漏**。
- **方案**：tA/tB 改用**原高斯在切平面上的投影椭圆**：原四元数局部轴 (ax0,ax1,ax2) × 对应原尺度 ls0/ls1/ls2，投影长 `s·sqrt(1-(axis·法线)²)`，取最大两个为半轴。**网格跨度 2tA、2tB 必然 ≥ 原覆盖范围**（数学上无洞；面积上 discR≈0.6L 时总覆盖 = 1.44·π·tA·tB ≥ 原椭圆）。
- **验证**：bump 5304 / flat 5634；激进 23679/23171；截图更密实非更透明。
- **UI**：结果标签新增 `Split: {split}`（实际追加数）。

### 4.7 v4 三项需求（仅表面分裂 / 先压扁再分裂 / 三类切断）—— 下午⑥

- **动机**：用户提出三项明确需求：
  1. **仅在物体表面产生分裂**（内部体积高斯不分裂）
  2. **凸起先压扁再分裂**（高斯球与平面夹角大的先压平）
  3. **三类直接「切断」（删除）**：过扁、过大、夹角超限的高斯球
- **方案**：
  1. **表面限制**：analyzer 加 `localFlatness = λ3/λ1`（邻域 PCA 平坦度，0=平面、1=各向同性），分裂条件加 `localFlatness < 0.4`。
  2. **先压扁**：保持压缩 → 对齐法线 → 判分裂的顺序（原实现已符合）。
  3. **Phase 2.5 切断 pass**（对所有高斯，`state[i]=1` 标记删除，渲染跳过）：
     - 超大：`mx > localThickness×12 || mx > diag×0.08`（相对为主 + 绝对兜底，避免孤立 shard 拉大 diag 稀释绝对阈值）
     - 过扁：`flatness < 0.1 && mx > localThickness×5`
     - 夹角超限：`flatness < 0.5 && cosA < 0.5 && mx > localThickness×3`（加 flatness<0.5 保护，避免误伤球状鼓包——球无主轴方向）
  - state prop 不存在时自动创建（uint8）。
  - `SurfaceRefineResult` 加 `splatsCut`，UI 加 `Cut: {cut}`。
- **验证**（综合模型 test-cut.ply：4000 球 + 300 内部 + 18 鼓包 + 3 shard + 3 pancake）：
  - **cut 6 精确命中**（3 pancake + 3 shard）
  - 内部 300 体积高斯只压缩**不分裂** ✓
  - bump 模型 cut 0（球状鼓包不误伤）✓
  - flat 模型 cut 6（pancake 全切）✓
  - Phase 2 仅 13ms，性能无退化 ✓

## 6. 经验教训汇总（跨项目可复用）

| # | 教训 | 细节 |
|---|---|---|
| 1 | **构建验证必须用 tsc** | rollup 语法错误消息是 "SyntaxError"/"Unexpected token"，**不含 "error:"**，`grep "error:"` 会漏掉静默失败的构建 → dist 陈旧 → 运行时诡异。用 `npx tsc --noEmit` 或看完整构建输出 |
| 2 | **serve 不要管道到 head** | `npx serve dist \| head -N` 日志超 N 行后 SIGPIPE 杀 serve。用 `> /tmp/serve.log 2>&1` |
| 3 | **puppeteer 访问用 localhost** | `127.0.0.1` 会被 Windows 系统代理拦截（Edge 默认走代理） |
| 4 | **PlayCanvas ShaderMaterial** | `setParameter('uniform', v)` 在 unified:false 旧管线不生效；`setDefine + update()` 才触发重编译；最可靠是源码硬编码 |
| 5 | **无头验证判据** | 截图文件大小 > 像素探针（drawImage 抓到离屏 canvas 读 [0,0,0,0]） |
| 6 | **Windows EPERM** | 瞬时文件锁（Defender/索引），构建失败时杀 node + 删 dist 重试，或等 2 秒重试 |
| 7 | **ls -la 误读** | Windows 下 `$5` 列可能是 uid（如 197121）不是文件大小 |
| 8 | **split 判据迭代** | 覆盖面积必须用「原高斯切平面投影椭圆」（tA·tB），不是压缩后尺度，也不是单轴 max |
