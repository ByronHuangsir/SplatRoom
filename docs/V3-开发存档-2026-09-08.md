## 调研结论（存档备忘）

- **PLY/SOG SH"符号翻转"不是 bug**：是 splat-transform 的坐标空间语义（Transform.PLY = 绕 Z 180°，SH 随空间旋转）。DataTable 需携带正确的 transform（SplatRoom 导出用 Transform.PLY → 正确，45/45 无翻转）。
- 3.4.0 全格式 round-trip（PLY/SPZ/KSplat/splat/SOG/compressed-PLY/glTF）点数一致无回归；SPZ/compressed-PLY 为有损量化（预期）。
- SplatRoom 主渲染仍是 WebGL2；WebGPU 仅用于 SOG 压缩路径（splatfactory / splat-serialize）。PiP 显式 `isWebGPU → return null`（不支持）。
