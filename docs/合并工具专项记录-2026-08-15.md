## 1. 功能背景与架构

「高斯合并」是 SplatRoom 的独立工具模块：把多个高斯模型合并为一个 PLY。独立窗口（`?mode=merge`）+ 独立 PlayCanvas 渲染链路（与主编辑器零共享）。

| 模块 | 文件 | 职责 |
|---|---|---|
| 入口 | `merge-app.ts` | 独立 canvas + Application + MergeScene + MergePanel |
| 场景核心 | `merge-scene.ts`（~2030 行） | 加载/选择/链锁/对齐/历史/相机/gizmo/输入 |
| 面板 | `merge-panel.ts` | 左侧四区：加载/模型管理/对齐模式/导出 |
| 数据模型 | `merge-model.ts` | MergeModel（entity+gsplat+AABB+链锁） |
| 对齐算法 | `merge-align.ts`（~1340 行） | kabsch / PCA / bestTransformAlign / **umeyamaSimilarity / similarityRecognize / raycastPick** |
| 导出 | `merge-export.ts` | buildMergedGSplatData → PLY（位置/旋转烘焙 + scale log 烘焙） |
| 渲染辅助 | `merge-grid.ts` + shader、`merge-view-cube.ts` | 无限网格、右上角坐标轴 |

**对齐三模式**：手动（gizmo+数值面板）/ 自动（PCA+ICP 刚体）/ **标记（3 组对应点 → 相似识别，含缩放）**。

## 4. 相似识别（核心升级）

### 4.1 设计

标记点从"精确对应"降级为**粗略种子**，最终配准由算法自动完成：

```
用户点 3 组标记 → Kabsch 粗配准（粗略参考）
        ↓
相似识别：几何 + 平面（点到面）+ 颜色（f_dc 加权最近邻）+ 形状（Umeyama 相似变换含缩放）
        ↓
种子扰动多候选（±6°/±4%）→ 综合评分选最优
        ↓
「待确认」：面板显示 缩放/旋转/几何/平面/颜色/覆盖/标记偏差 → 应用/撤销
```

### 4.2 关键实现（merge-align.ts）

- **`umeyamaSimilarity`**：SVD-free 相似变换（刚体+均匀缩放），复用 Jacobi 特征分解。
- **`colorWeightedIcp`**：颜色+几何加权最近邻（HashGrid）+ 自适应内点阈值（2.5σ 首轮放宽）+ 单轮缩放阻尼 [0.85, 1.18]。
- **`estimateNormals`**：HashGrid 邻域 PCA 法线（平面/法线评分依据）。
- **`similarityRecognize`**：采样（含 f_dc）→ 法线 → 多候选 ICP → 综合评分。

### 4.3 合成测试（mock PlayCanvas + tsc 单文件编译）

- umeyama 数值恢复（旋转30°+平移+缩放1.5）：误差 < 1e-6 ✓
- 端到端 ICP（8° 种子偏差，GT 缩放 1.2/旋转 25°）：s=1.199、覆盖 99.6%、平均距离 2% 半径 ✓

## 5. 回归①："变换异常"误报（2.3.1）

**现象**：标记对齐报"计算出的对齐变换异常（可能标记点退化）"，即使标记点很准确。

**根因（两层数值问题，由共面标记点触发）**：

1. **近零特征值污染 U 列**：kabsch/umeyama 判定"奇异值为零"用绝对阈值 `s > 1e-9`。共面标记点近零特征值（λ≈1e-14 浮点残差）开方后约 2.97e-7 **超过 1e-9** → U 列被数值噪声填充 → Gram-Schmidt 归一化后仍落在原有平面内 → R 缺一维（det=0）→ 误报。
2. **零列补基方向缺陷**：秩不足时只尝试 `[1,0,0]`，而已有列张成 XY 平面时该方向被完全消去而归零。

**修复**：
- 有效奇异值改**相对阈值**（σ_i > 1e-6·σ_max）。
- 零列补基**依次尝试三个坐标轴**，取第一个正交化后非零者。

**验证**：一般三角形/近似共线(1e-3)/两点接近(1e-4)/完全共线/大尺度 全 det=1、恢复误差 1e-5~1e-8 ✓；ICP 端到端回归 PASS。

> 注：共面/共线标记点本身信息不足，旋转方向由后续相似识别（全点云 ICP）锁定——符合"标记仅作粗略参考"设计。

## 6. 回归②：标记点错位大（2.3.2）

**现象**：海螺号角 01（尺度~45）与 02（尺度~100）合并，旧实现把 02 错误缩放×0.45 且标记点错位大（merged-2 vs 正常 merged-1）。

**三层修复**：

1. **标记锚点硬约束**：
   - ICP 每轮把 3 组标记点对**强制加入对应点集**（复制 anchorWeight=6 次加权）。
   - **关键 bug**：锚点源端此前固定，而普通点在候选变换/迭代中移动——坐标系不一致导致 Umeyama 每轮解震荡发散。修复：锚点源随候选变换（candAnchors）+ 随每轮迭代同步更新（anchorCur）。
   - 评分加入标记残差项（高权重 `weights.m=1.5 × 4`），选候选优先标记对齐。
2. **缩放先验**：由标记点距离比（dst/src 中位数）估计尺度；候选基准 = 缩放（绕锚点质心）+ 平移到目标质心的**精确标记变换**，扰动围绕该基准。尺度差异大的模型无需依赖 ICP 从刚体起步（否则内点阈值剔除全部对应、无法启动）。
3. 面板/状态区新增「标记偏差」指标。

**验证（模拟海螺场景：s=0.45/旋转6°/部分重叠）**：

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 缩放 s | 0.19-0.21（错） | **0.4500 精确** |
| 标记偏差 markerError | 25-43 | **0.0013** |
| 平均对齐距离 | 5-10 | **0.001** |
| 旋转 | 22-60°（错） | **6.00° 精确** |

回归：无锚点 ICP（s=1.2/rot=25°/覆盖 100%）✓、kabsch 退化场景全 PASS ✓。

## 9. 遗留问题与未来方向

- **非均匀缩放**：当前为均匀缩放（符合"大小匹配"直觉）；非均匀需分解 scale 轴，模型数据固有限制。
- **颜色/候选数可调**：权重与候选数目前代码内默认值，可考虑面板暴露。
- **主程序 group-renderer rot 顺序 bug**：探索中发现主编辑器 `group-renderer.ts` 的 rot 列序处理与引擎约定相反（merge-export 正确），属独立问题未修。
- **D4/D5 未做**：SOG transform position 应用（与 compare 一致暂不处理）；窗口关闭 destroy（独立窗口页面卸载即释放）。
- **更大偏差种子**：15° 以上旋转对称歧义会掉局部最优（合理边界，标记粗配准通常 <8°）。
