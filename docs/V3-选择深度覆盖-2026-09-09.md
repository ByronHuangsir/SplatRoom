# V3 专项记录 — 选择深度 / 覆盖 + 深度贴面球刷（2026-09-09）

## 目标（对标 SuperSplat 3.0 的 Selection 重设计）

SuperSplat 3.0（WebGPU 重写）把"选择"拆成两个正交开关 + 新球刷：

- **Selection Depth（仅表面）**：只有可见表面上的高斯可被选中（被遮挡的不再被误选）。
- **Selection Footprint（覆盖判定）**：判定一个高斯是否"命中"选择区域时按它的渲染覆盖（footprint）算，而不是只按中心点。
- **Sphere Brush（Shift+B）**：贴着可见表面滚动的 3D 球刷（深度拾取贴面）。

本版在 SplatRoom V3 落地**基础版**：两开关全工具生效（真实语义），球刷以新工具提供。

## 语义落地矩阵（全部为真实路径，无双开关同效陷阱）

对 2D 区域/点选（rect、brush/lasso/polygon/flood 的 byMask、单击 point）：

| surfaceOnly | useFootprint | 行为 |
|---|---|---|
| off | off | **传统中心判定**（穿透，可选中被遮挡高斯；保持 SplatRoom 历史行为）|
| on | off | **中心判定 + 仅表面**：GPU 判交时逐高斯比较 surface id map（中心像素必须是其自身在最前）|
| off | on | **覆盖判定（穿透近似）**：可见覆盖 ∪ 穿透中心（被遮挡但中心在区域内的高斯仍可被中心路径选中）|
| on | on | **可见覆盖**：像素拾取（区域内每个像素的正面高斯，SuperSplat 默认组合）|

3D 体积工具（sphere/box/球刷）：surfaceOnly 生效（体积内中心 ∈ 可见表面才选），footprint 不适用（文档化）。

## 实现要点

- **surface id map**：复用 Picker 的 ID pass（`pickOp='set'` 渲染除 locked/deleted 外全部高斯，NOBLEND + 排序 → 每像素存正面高斯 index，RGBA8 编码 32 位）。新暴露 `camera.renderSurfaceMap(splat)` / `Picker.idTexture`。
- **GPU 比较**：`intersection-shader.ts` 新增 `surfaceOnly`/`surfaceMap`/`surfaceMap_params` 三 uniform + `decodeSurfaceId`；对 mask/rect/sphere/box 四种 shape 命中后再比较中心像素 front id == 自身 id。
- **时序**：id 缓冲区在相机的共享 work target（`workBuffer`）里，**每帧都会被 splat pass 覆写**。因此 surface map 渲染必须与 intersect draw 放在**同一个 commandQueue 任务**内、紧邻提交（`runSelectIntersect` 内 `surfaceOptionsFor`）。任何提前渲染 + 跨 await 再判交都会读到被帧覆写的内容。
- **持久化**：localStorage `splatroom.selSurfaceOnly` / `splatroom.selUseFootprint`，默认 off。设置面板两行开关 + 快捷键 **N**（surface）/ **Shift+M**（footprint，避免与 M=rings 冲突）。
- **贴面球刷** `src/tools/sphere-brush.ts` + 底部工具栏按钮：拖拽记录采样（间隔 ≥ max(6px, r×0.35)，上限 512），松手后每个采样用 `camera.intersect`（深度拾取，返回可见表面世界点）做锚点，把半径为"屏幕半径在锚点深度换算的世界半径"的单位球 transform 发给 `select.bySphereBrush` → 逐 splat 逐采样 `runSelectIntersect`（surface 开则逐采样做表面比较）。多采样时显示 spinner。

## 已知边界（诚实标注）

- **footprint + depth off**：隐藏高斯的"覆盖"目前只能由中心路径近似捕获（可见像素路径天然只含正面）；真正按椭圆 footprint 穿透判交留待后续 GPU 扩展。
- **surface id map 按 splat 对象生成**：多 splat 实体场景下互不遮挡（与 SplatRoom 现有逐对象选择语义一致）。
- 球刷半径按相机 fov/距离换算（透视近似），正交投影按 orthoHeight。
- WebGPU 渲染后端下本特性未经真机验证（Picker/readback 路径 WebGPU 差异可能影响 id pass；V3 WebGPU 仍为实验开关）。

## 验证方式（真机项）

1. 载入前后遮挡明显的模型（如"墙后物体"）：默认关两开关时框选/刷子可选中被挡内容 → 开 surface（N）后同区域只能选到表面；开 footprint+surface 后与 rings 视觉覆盖一致。
2. 单击：surface 开时点击表面只选正面高斯；关时可连同 splatSize 内中心命中一起。
3. 球刷：选 Sphere Brush（球刷图标）沿表面拖动 → 选中球体扫过的表面高斯；开 surface 后不会钻到墙后。
4. `[`/`]` 调球刷/2D 刷半径；Alt+滚轮同 2D 刷。
5. 设置面板两个开关即时生效（无需重启），重启后保持。
