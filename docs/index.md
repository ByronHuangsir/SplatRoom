# SplatRoom 用户指南

SplatRoom 是一个开源的 3D 高斯泼溅（Gaussian Splatting）编辑器，支持在浏览器和 Windows 桌面端运行。它可以查看、检查、变换、调色、清理和优化 3D 高斯泼溅数据。

## 安装

### 网页版

直接在浏览器中打开即可使用，无需安装。

### 桌面版

下载 Windows 便携版 exe，双击即可运行，无需安装。

### PWA 安装

SplatRoom 支持 PWA（渐进式 Web 应用），可安装到桌面，.ply 文件将关联到 SplatRoom。

---

## 加载模型

支持三种方式加载 .ply 文件：

1. **拖放**：将 .ply 文件拖入 SplatRoom 窗口
2. **菜单**：选择 `Scene > Open` 菜单项
3. **URL 参数**：`?load=<PLY_URL>`

加载模型后，相机会自动聚焦到高斯点密集区域。

---

## 相机控制

### 基本操作

| 操作 | 功能 |
|------|------|
| 鼠标左键 / Shift + 右键 | 环绕相机 |
| 鼠标中键 / Alt + 右键 | 缩放相机 |
| 右键 | 平移相机 |
| 左/右方向键 | 左右平移 |
| 上/下方向键 | 前后移动 |
| F 键 | 聚焦选中模型 |
| 双击 | 设置环绕中心 |

### 摄像机面板

左侧摄像机面板提供精确的相机控制：

- **摄像机模式**：Orbit（环绕）/ Fly（飞行）
- **航向轴**：箭头按钮 15° 步进，数值框可拖拽（普通 1° 步长，Ctrl 0.05° 步长）
- **俯仰轴**：同上
- **视野角**：调整相机 FOV
- **惯性滑行**：开启后松开鼠标保持惯性动量

拖拽数值时，屏幕底部会显示 30° 范围的角度刻度尺。

### 预设视角

| 快捷键 | 视角 |
|--------|------|
| NumPad 5 / 1 | 正面 |
| NumPad 2 | 底面 |
| NumPad 3 | 侧面 |
| NumPad 7 | 顶面 |
| NumPad 0 | 重置 |

也可以通过右键菜单 > 视角 子菜单选择。

### 自动旋转

- **环绕**：相机绕场景中心 360° 旋转
- **环视**：相机原地旋转环视四周
- **关闭**：停止自动旋转

手动操作时自动旋转会暂停，0.8 秒后恢复。旋转速度可在面板中调整。

## 调色系统

SplatRoom 提供专业级非破坏性调色功能。原始 PLY 文件始终保持只读，调色参数存储在 `.sscg` 侧车文件中。

### 基础调色

基础调色面板包含以下滑块：

| 参数 | 范围 | 说明 |
|------|------|------|
| 色调 | -1 ~ 1 | 绿色 ↔ 洋红色调偏移 |
| 色温 | -1 ~ 1 | 冷色 ↔ 暖色 |
| 饱和度 | -1 ~ 1 | 整体色彩饱和度 |
| 自然饱和度 | -1 ~ 1 | 智能饱和度（保护已饱和区域） |
| 亮度 | -0.5 ~ 0.5 | 整体亮度 |
| 对比度 | -1 ~ 1 | 明暗对比 |
| 高光 | -1 ~ 1 | 高光区域亮度 |
| 阴影 | -1 ~ 1 | 阴影区域亮度 |
| 白场 | 0 ~ 2 | 最亮区域映射 |
| 黑场 | -1 ~ 1 | 最暗区域映射 |
| 透明度 | 0 ~ 1 | 整体不透明度 |

**双击滑块**可重置为默认值。

### HSL 逐通道调色

切换到 HSL 标签页，可对 8 个色区分别调整：

- **色区**：红色、橙色、黄色、绿色、青色、蓝色、紫色、品红
- **属性**：色相、饱和度、明度

共 24 个滑块，实现 Lightroom 风格的精细色彩控制。

### A/B 对比

- **按住**对比按钮：临时关闭调色，查看原始效果
- **松开**：恢复调色效果

### 吸管白平衡

点击吸管图标后，在画面中点击灰色区域，自动校正白平衡。

### 保存与加载

- `Scene > Save Color Grade`：保存调色参数到 `.sscg` 文件
- `Scene > Load Color Grade`：从 `.sscg` 文件加载调色参数
- 打开 PLY 文件时自动检测同名 `.sscg` 文件

### 导出烘焙

导出模型时，调色参数会自动烘焙到输出文件中。支持：
- Compressed PLY
- Splat File
- SOG 格式

## 去浮云工具

3D 高斯泼溅数据中常包含孤立的半透明高斯点（浮云），影响视觉效果。去浮云工具可以智能检测并移除这些噪点。

### 快速模式

仅使用两个参数快速检测：
- **透明度阈值**：透明度高于此值的点被视为浮云
- **体积阈值**：体积小于此值的点被视为浮云

### 精细模式

额外启用两个参数（快速模式下变灰不可用）：
- **隔离半径**：检查周围一定半径内是否有其他高斯点
- **距离阈值**：与最近高斯点的距离

### 使用流程

1. 选择"快速"或"精细"模式
2. 调整参数滑块
3. 点击"浮云预览"查看检测到的浮云（红色高亮）
4. 确认后点击删除

---

## 修补工具

删除高斯点后，可以使用修补工具填充空缺区域。

- **算法**：KNN（K-近邻）混合，用周围正常高斯点的颜色和属性填充
- **选区**：球体范围限定修补区域
- **抖动采样**：避免填充区域出现重复纹理

### 使用流程

1. 在底部工具栏选择修补工具
2. 调整球体选区大小
3. 在需要修补的区域拖拽
4. 支持 Undo / Redo

---

## 还原已删除高斯点

删除操作不会永久丢失高斯点，可以随时还原。

1. 在场景面板中，点击模型的"显示已删除"开关
2. 已删除的高斯点会以特殊样式显示
3. 选中已删除的点
4. 右键菜单选择"还原已删除"

---

## 选择与删除

### 选择工具

| 工具 | 说明 |
|------|------|
| 拾取选择 | 点击选择，拖拽框选 |
| 笔刷选择 | 拖拽圆形选区，`[` `]` 调整大小 |
| 球体选择 | 球体体积选区，双击重新定位 |

### 右键菜单

- **复制 / 剪切 / 粘贴**：Ctrl+C / X / V
- **视角**：预设视角子菜单
- **还原已删除**：还原选中的已删除点

选中高斯点后按 Delete 键删除。

---

## 变换

选中模型后，通过底部工具栏激活变换 Gizmo：

- **移动**：平移模型
- **旋转**：旋转模型（每个轴有 90° 快速旋转按钮）
- **缩放**：等比缩放模型

变换面板（场景面板下方）提供精确的数值输入。

---

## 多模型拼接

### 多选与编组

1. 在场景面板中 **Ctrl+Click** 多选模型
2. 点击**链锁图标**将选中模型编组
3. 编组后相机绕联合中心旋转
4. 再次点击链锁图标解绑

### Group 渲染

编组后，GroupRenderer 会将所有模型的高斯点合并为统一实体进行全局深度排序，确保任意视角下遮挡关系正确。

### 合并为新模型

编组后，点击**合并按钮**将多个模型烘焙合并为单一 PLY 文件。

### 编组内单体编辑

编组状态下，仍可选中单个模型进行移动、旋转等变换操作。

---

## 时间线动画

### 轨道系统

时间线面板包含两条轨道：
- **摄像机轨道**：记录相机位置和朝向
- **颜色轨道**：记录调色参数变化

### 关键帧

1. 开启"摄像机路径调整"
2. 调整相机到目标位置
3. 点击"添加关键帧"按钮
4. 在时间线上拖拽关键帧调整时间点
5. 右键时间轴可添加/删除关键帧

### 贝塞尔曲线

- 拖拽关键帧两侧的控制柄调整路径曲率
- 弧长重参数化确保匀速运动

### 画中画预览

- 可拖动的浮动小窗
- 实时预览当前时间帧的相机画面
- 异步独立渲染管线保证排序正确

---

## 视频导出

### 路径动画视频

沿时间线关键帧路径生成视频：
1. 创建摄像机路径动画
2. 设置运镜速度
3. 通过渲染菜单选择视频导出
4. 设置分辨率和帧率
5. 导出

### 旋转台视频

360° 环绕场景生成视频：
1. 通过渲染菜单选择"旋转台视频"
2. 设置分辨率、帧率和旋转速度
3. 导出

---

## 数据面板

数据面板（底部，按 D 键展开）以直方图展示场景属性分布。可在直方图上拖拽选择高斯点，Shift 添加到选区，Ctrl 从选区移除。

---

## 导出格式

| 格式 | 说明 |
|------|------|
| PLY | 标准高斯泼溅格式 |
| Compressed PLY | 压缩格式，量化并丢弃球谐函数 |
| Splat File | 另一种压缩格式 |
| SOG | 针对 Web 优化的格式，支持超大文件分条 WebP 编码 |

导出时调色参数会自动烘焙到输出文件中。
